# Veri Tipleri
Veri tiplerini bilmek Python'a giriş yaparken çok önemli bir adımdır. Programımızı yazarken nerde hangi veri türünün kullanılacığını bilip uygun olanı seçmemiz porgramımızın amacına uygun olarak çalışması için çok kritiktir. Mesela bir muhasebe programı yazarken ondalık sayılardan faydalanırız eğer tam sayılarla işlemler yaparsak parasal hesaplarda muhasebeci için yanlış çıktılar vermiş oluruz.

**Aşağıda veri tipleri verilmiştir.**

- Metin tipleri: str

- Sayısal tipler: int , float , complex

- Dizi tipleri:  list , tuple , range

- Adresleme tipleri: dict

- Küme tipleri: set , frozenset

- Mantıksal tipler: bool

- Binary tipler: bytes , bytearray , memoryview

Bazı dillerde örneğin C dilinde proglama yaparken değişkenimizin türünü de belirtmemiz gerekir ancak Python programlama dilinde bir değişken oluştururken o değişkenin tipini belirtecek bir terim kullanmanıza gerek yoktur. ```

# Fonksiyonlar 
Fonksiyonlar çağrıldığında çalışan, belirli bir işlevi yerine getirmek için kullanılan kod bloklarıdır. Defalarca veya kodun ilerleyen bölümlerinde kullanılmak üzere tanımlanırlar. Kod büyüdükçe ve ilerledikçe fonksiyonlar sayesinde tekrarlayan işlemler daha düzenli yönetilebilir.

```python

    print("selam, merhaba")
```

```text

```
Fonksiyonlar aslında daha da işlevseldir biz basit bir print örneği yaptık. Bu işlevselliğe örnek olması açısından selam fonksiyonu geliştirilebilir.

# Class

Class nesne ya da nesneye yönelimli programlamın en önemli kavramlarından bir tanesidir. 

Class birbirleri ile ortak özellikleri olan nesneleri gruplandırmaya yarıyor. Böylece daha düzenli bir program yazmış oluyoruz.

Mesela meyveler bir class olarak düşünelim elma , armut , şeftali de nesne olur. Herbirinin ayrı özellikleri vardır mesela kilo fiyatı , son kullanma tarifi gibi gibi. Ama ortak olarak hepsi meyvedir işte bu yüzden class olarak meyve sınıfındadırlar. 

Class oluşturmak için 'class' anahtar kelimesini kullanırız.

Aşağıda class sınıfı nasıl yapılır deniyelim.

```python
class meyveler:
    pass
```

Aşağıda 'pass' yazmak yerine nitelik yazalım classımız için.

```python
class calisan:
    def __init__(self,name,surname,age):
        self.name = name
        self.surname = surname
        self.age = age
calisan1= calisan("İlayda","Kaplan",20)
print(calisan1.name,calisan1.surname,calisan1.age)
```
```text
İlayda Kaplan 20
```


**__init__** Bir sınıftan yeni bir nesne ürettiğiniz anda arka planda otomatik olarak çalışan fonksiyondur. Görevi, o nesne oluşturulurken ona başlangıç özelliklerini yüklemektir. Bizim yukarıda yaptığımız örnek üzerinde düşünürsek fiyat ya da renk dememiz mümkün.

Self ile kullanılır çünkü sınıflar birer üretim kalıbıdır ve bu kalıptan aynı anda hem elma hem de muz üretebilirsiniz. Self kelimesi, o an işlem yapılan spesifik nesnenin kendisini temsil eder. Böylece Python, elmanın fiyatı ile muzun fiyatını birbirine karıştırmaz.



Şimdi aşağıda konuyu daha iyi kavramak için bir örnek yapalım. İlk başta ağır gelecek ama yazıyla kavramlara açıklama getireceğiz.

```python
class Meyveler:
    def __init__(self, urun, renk, fiyat, kilo):
        self.urun = urun
        self.renk = renk
        self.fiyat = fiyat
        self.kilo = kilo

    def odenecek_tutar(self):
        tutar = self.fiyat * self.kilo
        return tutar

meyve1 = Meyveler("Elma", "Kırmızı", 30, 2.5) 
meyve2 = Meyveler("Muz", "Sarı", 60, 2)        
meyve3 = Meyveler("Üzüm", "Yeşil", 45, 1)      


print(f"{meyve1.kilo} kilo {meyve1.renk} {meyve1.urun} için ödenecek tutar: {meyve1.odenecek_tutar()} TL")
print(f"{meyve2.kilo} kilo {meyve2.renk} {meyve2.urun} için ödenecek tutar: {meyve2.odenecek_tutar()} TL")
print(f"{meyve3.kilo} kilo {meyve3.renk} {meyve3.urun} için ödenecek tutar: {meyve3.odenecek_tutar()} TL")

```
```text
2.5 kilo Kırmızı Elma için ödenecek tutar: 75.0 TL
2 kilo Sarı Muz için ödenecek tutar: 120 TL
1 kilo Yeşil Üzüm için ödenecek tutar: 45 TL
```

Şimdi bu programı biraz detaylandıralım.

- Metin tırnaklarının hemen başına konulan f harfi metinlerin içine Python değişkenlerini çok pratik bir şekilde yerleştirmenizi sağlar. Tırnak işaretinden önce f yazdığınızda, metnin içinde süslü parantezler { } açabilirsiniz. Python, bu parantezlerin içine yazdığınız kodları metin olarak değil, değişken olarak algılar ve hesaplayıp sonucunu doğrudan cümlenin içine gömer.

- Meyveler adında bir class yaparak tüm meyvelerin ortak özelliklerini ve yapabileceği işlemleri barındıran bir ana şablon tanımladık.

- def __init__ sayesinde özellikleri kaydettik. 

- def odenecek_tutar sayesinde elimizdeki değerler üzerinden işlemler yaptık. Yazımızda daha önce öğrendiğimiz şekilde fonksiyon yazmış olduk.

- Özetle class yapısını kullanarak tek tek her meyve için ayrı hesaplama denklemleri yazmak yerine, akıllı bir şablon oluşturup işi o şablona bırakmış olduk. Sistem bu sayede 10000 farklı meyve daha eklesek bile kodu uzatmadan tek satırda hesaplama yapabilir hale geldi.
